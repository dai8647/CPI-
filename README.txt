■これは何か
  「東京都区部の消費者物価指数（速報）」は毎月月末に、それより約3週間
  遅れて「全国の消費者物価指数（速報）」が公表されます。
  このファイルは、東京の最新速報から回帰式で全国の数値を
  先回りして予想するツールです。
  ・予想対象は「総合」「コア（生鮮除く）」「コアコア（生鮮・エネ除く）」の3系列
  ・全国の総合指数（水準）も併せて表示

■使い方はこれだけ
  1. CPI.xlsm を開く（マクロの有効化を聞かれたら「有効にする」）
  2. メインパネルの「▶ 全自動更新」ボタンを1回押す
     → 約10〜30秒で、
        ① e-Stat から最新データ取得
        ② 回帰係数の推定
        ③ 全国CPIの予想計算
        ④ 推計履歴への保存
        が全部自動で終わります。
  予想はセル C20〜C23（総合・コア・コアコア・全国指数）に出ます。
  対象月（C7）は「東京の最新月」に自動でセットされます。触らなくてOK。

■いつ押すか（毎月のリズム）
  ・月末（26日ごろ）: 東京都区部の速報が出たら → 押す → 翌月17日頃公表の
    全国値を予想できる
  ・翌月17日頃: 全国の速報が公表されるので、また押すと実績がデータに入り
    係数が自動で更新される。推計履歴シートに「予想したとき」の記録が
    残るので、あとで実績と見比べられる

■予想のロジック（正しい根拠のあるやり方）
  全国の前年比 = α × 東京の前年比 + β
  ・3系列それぞれに α・β を個別に推定（決め打ちの共通係数は廃止）
  ・係数は直近12か月で毎月やり直し（窓の長さは C14 で変更可）
  ・精度: 過去約9年を「1か月先の予想」で追ったバックテストで
    平均誤差 約0.15pt（回帰診断シートに内訳）
  ・全国指数の水準 = 昨年同月の指数 × (1 + 予想前年比) の連鎖方式
  ・データ源: e-Stat「消費者物価指数（2025年基準）」統計表ID 0004052037
    （2026年10月の基準改定に対応した最新の表。旧基準の数値とは多少違う）

■シートの説明
  メインパネル … 操作と結果（ボタン・予想値・係数）
  データ         … e-Statから取得した月次データ（黄色いB2は自分のAPIキー）
  推計履歴       … 全自動更新を押すたびに1行ずつ記録
  回帰診断       … 系列・窓ごとのバックテスト精度
  説明           … ファイル内の詳しい説明（同じ内容をわかりやすく）

■いじっていいのは黄色のセルだけ
  C7  対象月（通常は自動で入る。手动で別月に変えることもできる）
  C14 回帰窓の長さ（既定12か月）
  データ!B2  自分の e-Stat APIキー
  ほかのセルには書き込まないでください（上書きされると計算がずれる）

■補足
  ・ネットにつながる環境で使ってください（ボタンを押すたびに e-Stat から最新を取得します）
  ・VBAは「ModuleCPI」モジュール1本に整理しました（旧Module1/2/3の
    旧ロジックは削除済み）
  ・マクロエラーのダイアログは出さない設計です。失敗したときは
    メインパネルのステータス欄（B35）に赤いエラーメッセージが出ます

==============================================================
 R* (Holston-Laubach-Williams) 推計 モジュール
==============================================================

■R*とは
  潜在成長率と自然実質金利を推計するマクロ経済モデル。
  カルマンフィルタ + RTSスムーザで実時間/スムーズ推計。

■使い方
  1. RSTARシートを開く
  2. パラメータセル（黄色）を確認・必要に応じて修正
  3. データ表（A13:）に入力: label, log_output, inflation, exp_infl, real_rate, nom_rate
  4. Alt+F8 → ModuleRStar.RStar_Run を実行
  5. 結果がデータ表の下の行に出力される

■パラメータ
  lambda_hlw   : HPフィルタ重み（通常36000）
  lambda_cpi   : CPI用HPフィルタ（通常1600）
  lw_weights   : LWメジアン不偏の重み（0.5/0.3/0.2/0.1）
  mu_start     : LW推計期間開始（通常1995Q1）
  mu_end       : LW推計期間終了（通常2007Q4）
  zlb_floor    : ゼロ金利床（通常0.1）
  pi_source    : 期待インフレ源（defl_sa）
  rstar_auto   : 全自動更新ON/OFF（ONでAutoUpdate末尾で自動実行）

■データ取得
  (a) 内閣府 四半期別GDP速報 CSV (版番号は自動検出):
      実質GDP      gaku-jgXXXX.csv (原系列・2020暦年連鎖価格, 列=国内総生産(支出側))
      消費デフレ   def-qgXXXX.csv  (原系列・2020暦年=100, 列=民間最終消費支出)
      例: 2026年4-6月期2次速報 = .../files/2026/qe262_2/tables/gaku-jg2622.csv
  (b) 日銀コールレート: https://www.stat-search.boj.or.jp/api/getDataCode?format=csv&code=STRACLUCON
      → SURVEY_DATES月次、3か月平均を四半期化
  (c) コアCPI: 既存データシート列F

■APIキー再発行手順
  1. https://www.e-stat.go.jp/account/login よりログイン
  2. マイページ → APIキー発行
  3. CPI.xlsm データシート B2 にペースト

■テイルールール (政策金利の目安) — 金利予想シート
  新シート「金利予想」に計算表とグラフを追加しました。式は:
    i_eq(t) = r* + pi(t) + b_pi*(pi(t) - pi*) + b_y*gap
    i(t)    = i_eq(t) + rho*( i(t-1) - i_eq(t-1) )     [短期金利の平滑化]
  パラメータ (B4:B12・黄色セル):
    B4 目標インフレ率 pi* (%) = 2.0   B5 インフレ乖離係数 b_pi = 0.5
    B6 産出ギャップ係数 b_y = 0.5      B7 金利の平滑化係数 rho = 0.5
    B8 現行政策金利 (%) = 1.25           B9 CPI系列 (1=総合 2=コア 3=コアコア) = 2
    B10 r* の扱い (0=モデル値 1=手動)   B11 r* 手動上書き (%)   B12 産出ギャップ手動上書き (%)
  ■B8「現行政策金利」は日銀の目標金利を毎日銀の決定会合後に【手動更新】してください
    (年8回の更新が必要)。日銀時系列DBには目標金利の系列がなく自動取得できないため。
    参考として市場無担保コールレート (日銀APIで自動取得・月平均) を前提行に併記します。
    実績の推移: 2024/04 0.08% → 2024/08 0.23% → 2025/02 0.48% → 2026/01 0.73%
    → 2026/09 1.04%、2026/10 決定で 1.25%。
  入力: r* と産出ギャップは Rstar シートの最新の値 (model),
        pi(t) は全国コアCPIの予想パス (対象月は回帰予想、以降は AR(1) パス
        x(t) = pi* + rho*(x(t-1) - pi*) で目標へ緩やかに収束)。
  出力: 均衡政策金利 i_eq と、平滑化を入れた政策金利の目安 i、
        現行政策金利との差 (メインパネル ④ ブロックに要約表示)。
  ■r* 感応度 (A29:B34 の表 + グラフ「RateChart2」): 日銀レビュー 2026-J-5 の r* 推計レンジ
    (▲0.9%〜+0.5%) で i_eq のレンジを表示します。
    下限 r*=-0.9% → 1.63% / 中心 0% → 2.53% / 上限 +0.5% → 3.03%
    / 本ツールのモデル値 0.75% → 3.29%
    現在の政策金利 1.25% はこのレンジの下端付近 = テイルールール上の
    「金融緩和度合い」はまだ約 2pt ある、という読みです。
  注意: 本ツールの r* (0.75%) は日銀レンジの上端より上です。r* は B10/B11 で
    手動上書きして、日銀レンジの中央 (0%) を使うTouchable.policy  попуラーさを
    選ぶこともできます (i_eq は 2.5% 相当まで下がります)。

  ■B8「現行政策金利」を変えると何が変わるか
    ・変わるもの: 政策金利の目安 i(t) のパス全体の起点 (1期目)、
      「現行との差 (pt)」列、グラフの現行政策金利の水平線、
      メインパネル ④ の差。政策金利が高いほど差(pt)は小さくなる。
    ・変わらないもの: 均衡政策金利 i_eq (r*, CPI予想, 産出ギャップ, b_pi, b_y
      のみで決まる)、全国CPI予想パス、r* と産出ギャップ。
    ・収束先は同じ (12期目 ≈ 3.29%) だが、起点が高いほど早くそこへ着く。
      実測: B8=0.5% → 2.45%→3.29% (差2.78pt) / 1.25% → 2.83%→3.29% (差2.03pt)
            2.0% → 3.20%→3.29% (差1.28pt) / 2.5% → 3.45%→3.29% (差0.79pt)
  ■全国CPI予想の出典
    ・対象月 (例: 2026/09) は メインパネルの既存回帰予想 (全国 = α×東京 + β) を
      そのまま使います (既存の CPI 予想と同一の推計値)。
    ・2ヶ月目以降は AR(1) パス (目標 π* に係留した東京系列の自動予想) に既存の
      回帰式を適用して作ります。既存ツールは対象月1ヶ月先しか予想しないため、
      この12ヶ月パスだけは新しい推計部分です。
    ・系列は B9 で 総合/コア/コアコア を選択 (テイラールールには日銀の目標
      である コア を推奨)。
  ■原油シナリオ (A36:F50・グラフ3「RateChart3」)
    原油価格 (CPI の大きな構成比) のシナリオをセルで定義し、CPI パススルーを
    通じて政策金利シミュレーションに反映します。
    B37 基準指数 (=100)
    B38 CPIパススルー (指数 +10 あたり CPI +pp)  例: 0.3
    B39 選択シナリオ (1=上昇 2=基準 3=下落)
    定義表 A41:E44 (各シナリオ: 開始月 / ピーク月 / 振幅(%) / 残存(%))
      上昇  開始3 ピーク6 振幅+25 残存+8   (3ヶ月後に上がり6ヶ月目がピーク、12ヶ月目で+8に鎮静)
      基準  全て0
      下落  開始6 ピーク9 振幅-20 残存-8
    指数パス (A47:M50) とシナリオ別の政策金利パス (P15:AB19) は計算結果。
    選択シナリオの指数パスが将来月 (対象月を除く11ヶ月) の CPI 予想に反映され、
    i_eq と政策金利の目安が再計算されます。
    実測: 上昇 → 4ヶ月目 CPI 2.42→2.67%、政策金利の目安 12ヶ月目 3.28→3.64%
          下落 → 政策金利の目安 12ヶ月目 3.28→2.92%
    振幅・パススルーは日本の経験値を推奨 (原油 +25% で CPI +0.75pp 前後)。
  ■更新のタイミング
    ・金利予想シートは「◆全自動更新」の最後に書き直されます
      (データ取得 → 回帰推定 → 全国CPI予想 → R* → テイラールール)。
    ・「R*推計更新」ボタン単体では更新されません (全国CPI予想が必要で、
      前提に e-Stat からのCPI取得済みのため)。

■シート構成
  RSTAR ... R*推計専用シート（パラメータ・データ・結果）
  金利予想 ... テイラールールによる政策金利の目安
    グラフ1 (A37): 政策金利の目安パス / 全国CPI予想 / 現行政策金利 / 均衡政策金利 i_eq
    グラフ2 (A58): r* の根拠による i_eq のレンジ (下限・中心・上限・モデル値・現行政策金利)
  トレンドチャート ... CPI 実系列と乖離（自動更新）
  グラフ4枚 (自動生成・入力表の下に 2x2 配置):
    1. LHW r* (Kalman フィルタ/スムーザ) と実質観測金利
    2. LW r* (加重潜在成長率+μ) と実質観測金利
    3. LHW 潜在成長率 g* (フィルタ/スムーザ) と実質GDP成長率
    4. LHW 産出ギャップ (フィルタ/スムーザ) と HPフィルタ・日銀需給ギャップ
  「R*推計更新」ボタンで再生成されます。
  ■軸の分け方: 桁が大きく異なるため、グラフ1-3 は「観測系列=主軸(左) /
    モデル系列=二次軸(右)」に分離しています (r* は 0〜1.5% 程度、実質金利は
    −5〜+4% 程度なので同一軸ではDetails が潰れます)。
    グラフ4 は 3 系列とも同じ「産出ギャップ(%)」なので口径比較用に単軸のまま。
  ■グラフ1-3 の表示期間は 2000Q1〜 (カルマンフィルタの初期過渡を避けるため。
    結果は表には 1996Q1 から全期間掲載)。

■トレンドチャートシート (CPI 実系列)
  A:年月 B:東京総合 C:東京コア D:東京コアコア
  E:全国総合 F:全国コア G:全国コアコア H:全国-東京 乖離(pp)
  「データ取得」「全自動更新」で自動更新されます (直近24ヶ月)。
  グラフ1 = 前年同月比 6系列 (同一単位なので単軸)
  グラフ2 = 乖離のみ (全国−東京, pp) — 乖離を数値で直接読めるようにした

■結果表の列構成 (Rstar シート 431行目〜)
  A 四半期 / B r* Kalman(フィルタ) / C r* Kalman(スムーザ)
  D g*(フィルタ) / E g*(スムーザ)
  F 産出ギャップ(フィルタ) / G 産出ギャップ(スムーザ)
    ※ 定義 = 実際の y100 − モデル潜在 y100 (FRBNY の output.gap と同じ量)
  H 実質金利(観測) / I r*_LW / J 実質GDP(前年同期比)
  K z状態 (r* = 4g* + z の分解項・参考値)
  L 産出ギャップ (HPフィルタ・独立推計とのベンチマーク)
  M 産出ギャップ (日銀需給ギャップ・別口径のベンチマーク)

■外部ベンチマークとの比較 (2026-10-21 調査)
  ■r*: 日銀レビュー 2026-J-5「自然利子率の動向と金融緩和度合いの評価」
    (https://www.boj.or.jp/research/wps_rev/rev_2026/data/rev26j05a.pdf) は
    6モデルのうちモデル③に **HLW[2023] を採用**し、日本の r* を推計している。
    推計レンジは 2023/1Q 時点 ▲1.0%程度〜+0.5%程度、2025/3Q 時点
    **▲0.9%程度〜+0.5%程度**。本ツールの推計 (2026Q2 = 0.75%) はこのレンジの
    **上端付近**。方向も一致 (日銀レビューは「多くの推計値が緩やかに上昇」と
    言及、本ツールも 2022年 0.66% → 2026Q2 0.75%)。
    内閣府「中長期の経済財政に関する試算」の潜在成長率 2026年度 = 0.5% とも整合。
  ■産出ギャップ: 日銀「需給ギャップ」(gap.xlsx, 1983Q1〜2026Q2) が M 列に入る。
    2009Q2: 本ツール ▲5.5% / 日銀 ▲4.79% → ほぼ整合
    2026Q2: 本ツール +0.76% / 日銀 +0.55% → 同符号・同オーダー
    2020Q2: 本ツール ▲8.7% / 日銀 ▲2.60% → **口径差**。
      本ツール (=HPフィルタ型 GDPギャップ) はコロナ期の日本の慣例値
      ▲8〜12% と整合、日銀の需給ギャップは生産関数ベースで振れ幅が小さい。
      同じ「産出ギャップ」名でも定義が異なるため、グラフ4では両系列を
      並記して口径差を可視化している。
  ■期待インフレの市場ベース系列: 日本の「1990年代〜現在まで連続で
    機械可読の四半期系列」は存在しない (日銀時系列DBに市場予想調査なし、
    物価連動国債は2013年以降のみ)。実務で使えそうなのは
    短観「企業の物価見通し」(db=CO&code=TK99F0000204HCQ00000 ほか、
    2000Q1〜) と日銀生活意識アンケート (2006Q6〜) だが1990年代を欠く。
    本ツールは既定でデフレーター4四半期平均（1994Q1〜連続）を採用。


■HLW パラメータ (Rstar シート D列ラベル / E列値・黄色セル)
  sigma_y* 下限 : 0.2    (MLE の識別失敗を補う下限。上限 1.0 程度)
  lambda_g      : 0.192798 (Stage1 median-unbiased)
  lambda_z      : 0        (Stage2 median-unbiased・日本のデータでは 0 と区別不能)
  a_3 制約      : -0.0025  (HLW の仕様どおり固定・上限制約)
  b_2 制約      : 0.025    (HLW の仕様どおり固定・下限制約)
  変更後は「R*推計更新」で再計算されます。

■zip を解凍したら (マクロのブロック解除)
  Windows 標準の「すべて展開」で解凍すると、セキュリティのためマクロが
  無効になることがあります。開けないときは:
    PowerShell で: Unblock-File "<解凍先>\CPI.xlsm"

■注意事項
  - R*推計はCPI予想と独立。失敗してもCPI結果は影響されない
  - Python COM経由での呼び出しは制限あり。Excel VBAから実行推奨
  - 固定係数はPython rstar_check.py のグラウンドトゥルース値を使用


【突合結果】R*の数値について (2026-10-17)
  ModuleRStar のカルマン部分は rstar_check.py (_unpack_stage3 +
  kalman_states + RTS スムーザ) の完全移植です。固定係数
  (theta/xi00/P00) は rstar_fixed_coeff.csv (Python MLE 結果) を
  ハードコード。VBA 出力と Python 参照 (rstar_vba_check.csv) の突合:
  filtered r* 最大差 5.7e-8 / smoothed 最大差 1.9e-7 (浮動小数点誤差の範囲)。
  r* は 1995Q1=0.51% から 2025Q1=0.75% で推移 (ZLB 下限 0.1% 適用済み)。
  注意: theta は MLE が下限に張り付いた解 (sigma_y=0.01 等) を含み、
  lambda_g=lambda_z=0 で固定しているため、再推定時は rstar_check.py の
  再実行と rstar_fixed_coeff.csv の張り直しが必要です。

【データ取得】(2026-10-20 更新)
  RStar_FetchData: VBA だけでデータ取得 (Python 不要・e-Stat キー不要)。
   1. 内閣府 四半期別GDP速報 CSV (最新版を自動検出):
      - files_sokuhou.html → 最新年 toukei_YYYY.html → 最新 qeNNN(_K) ディレクトリ
      - 実質GDP = gaku-jgXXXX.csv 列2 (国内総生産(支出側)・原系列・2020連鎖価格)
      - 消費デフレ = def-qgXXXX.csv 列3 (民間最終消費支出・原系列)
      速報は確報 xlsx より新しい四半期まで更新される (2026-10-20時点で 2026Q2 まで)。
      確報から速報への系列切替に伴い、xi0 (カルマン初期状態) は HP トレンドから
      動的計算に変更 (Python の xi00=None 既定と同一ロジック・再校正不要)。

【v5 較正 2026-10-21 (産出ギャップの識別回復)】
 1) 診断: FRBNY 原コード (unpack.parameters.stage3.R / rstar.stage3.R) との照合により
    - a_3 = -0.0025 と b_2 = 0.025 は「推定値」ではなく HLW の固定制約 (仕様どおり)
    - Q[6,6] = (λ_z·σ_y~/a_3)² なので λ_z=0 のときギャップ状態は定数運動しかできない
    - λ_z の median-unbiased 推定 (Stock-Watson) が日本のデータでは 0 (0 と区別不能)
    - 残る識別失敗は σ_y*: MLE が下限 0.01 に張り付き、潜在成長率が決定論的になる
    → 期待インフレ定義 (4Q平均/2期MA/適応的k=0.3,0.5/前方4期平均 の5通り) を
      全て試したが、尤度平坦度は定義によらず ~0.02 で識別は改善せず (期待定義は
      現状維持)。結論: λ_z と σ_y* は日本のデータでは外生パラメータとして較正する。
 2) 較正: σ_y* ≥ 0.20 の下限制約 (識別制約) を課し MLE を再実行。
    - 尤度差は 2.4 点 (|-490.66| vs |-488.24|) で無視可能
    - 産出ギャップの定義を FRBNY と同じ「実際の y100 − モデル潜在 y100」に修正した結果、
      HP フィルタのギャップ (日本の標準推計) と RMSE 0.147% で整合
      (2009年 -5.5% / 2020Q2 -8.7% / 1996Q1 +3.9%)
    - r* は 0.50〜0.87% の現実的な経路 (1996 0.83% → 2008 0.50% → 2019 0.55% →
      2026Q2 0.75%) になり、日本の r* 推計レンジと整合
 3) 検証: VBA vs Python (同一定数・同一入力) の全系列 max差 1.2e-8、

【v2 構成への移行 2026-10-17 (FRBNY 流見直し)】
 数式 (インフレ=400×ΔlogP, 期待インフレ=過去4四半期平均, 実質金利=名目−期待) は
 FRBNY の prepare.rstar.data.us.R と最初から一致していた。決定的な違いは物価指数の
 選択: FRBNY はコアPCE (消費ベースで平滑) を使うのに対し、旧構成は GDPデフレーター
 (消費税・エネルギー価格が直撃する高ボラティリティ指数) だった。このため:

 1) インフレ源を 民間最終消費支出デフレーター (同一内閣府 xlsx 内・PCE の SNA 版) に変更
 2) λg/λz は MLE版 stage1/2 からは推定しない (MLEの潜在出力が過度に平滑になり
    λ→0 に退化するカスケードが起きるため)。OLS初期化版 stage1/2 のメディアン不偏推定量
    (Stock-Watson 1998, FRBNY と同一実装) を用いる: λg=0.1851, λz=0.0722
 3) 固定係数を rstar_fixed_coeff_v2.csv に更新 (theta4=0.237, sigma_pi=1.862 ほか)

 結果: 産出ギャップは依然小さい (σ_y~ が下限張り付き) が、r* (Kalman) には動学が
 復活した: 1996年 1.2% → 2000年代 1.5% → GFC で急落 → 2019年 マイナス → コロナで

【r* の解釈（誤用しないための注意）】
 ・本ツールの r* は HLW(FRBNY) の定義「r* = 4×潜在成長率 + z状態」であり、
   「IS曲線から逆算した自然実質金利」ではない（FRBNY も同じ定義）。
 ・したがって観測実質金利 (i − 期待インフレ) と r* を単純に比較して政策金利の
   ギャップを推論することはできない。日本の実質金利は −1〜−4% で r* 0.75% と
   大きく離れるが、これは期待インフレ定義（デフレーター4四半期平均 = 2.5%）が
   政策金利（0.5%）を大きく上回るため。
 ・ギャップとして妥当なのは「産出ギャップ (F/G列)」で、HPフィルタ型
   GDPギャップおよび日銀需給ギャップと口径比較できる。
